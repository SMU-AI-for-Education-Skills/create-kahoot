## Purpose
Generates an Excel file containing 10 MCQs in a Kahoot import-friendly format from selected course material. 

## Using the skill 
You may download the latest version of this skill as a ZIP file under `Releases` on the right of the GitHub Repository page. You may refer to our guide to learn how to [use this skill within your AI tools](https://github.com/SMU-AI-for-Education-Skills#accessing-and-using-skills). 

## How this works
Provide course materials such as slide text, reading materials, or transcripts for this skill to prepare an Excel file containing 10 MCQs, formatted for direct import in Kahoot. The skill guides AI to follow best practices and Kahoot-friendly formatting in generating MCQs. 

## Inputs Required
You are required to provide course materials such as slide text, readings, or transcripts. After 10 MCQs are drafted by AI, you will be requested to review the generated output.

## Notes and Limitations
For best results, add and enable an Excel spreadsheet generation skill.
